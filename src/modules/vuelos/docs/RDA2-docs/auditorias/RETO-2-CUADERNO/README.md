# Cuaderno Reto 2 — Integración de Sistemas
Guía corta para rellenar a mano el cuaderno con los temas de las semanas 7 a 11.
Viene del Word «TEMAS RETO 2 INTEGRACIÓN DE SISTEMAS», aplicado a RAM Alliance Vuelos.
Abre `RETO-2-INTEGRACION-MI-SISTEMA.md`: tabla resumen, una viñeta por tema, un diagrama por semana.
Cada viñeta: concepto corto + «En mi sistema» (con archivo clave); lo faltante dice «No implementado».
Al final hay frases honestas para lo que no existe (Pact, OpenTelemetry, mTLS, etc.).
